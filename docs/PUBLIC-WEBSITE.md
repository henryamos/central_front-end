# Public website UI

The public routes follow the sitemap in CCC-SDA-PRD.md. The visit page and homepage use the same weekly gathering records. Planned visits and attendance use separate screens. Both forms show an unavailable state until guest intake, service context and approved consent handling are connected. They send and store no personal information.

The ministry directory links to the eight supplied ministries and the three music groups. Worship uses an announced stream when supplied and otherwise shows the regular service and latest available recording. Event and sermon detail routes are generated from published records. The gallery filters the photographs already supplied for the homepage. Resources include church news, articles, bulletins and visitor questions. The beliefs and international news links go to the worldwide church.

Publication collections live in the frontend until the CMS is connected. Production still needs approved history, ministry information, leader profiles, sermons, events, bulletins, verified desk contacts and directions, and treasurer-approved giving instructions. Guest intake, payments, officer workflows and private accounts are outside this public UI pass.
