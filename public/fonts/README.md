# Local website fonts

DM Sans is the current visual preview, served with next/font/local and display: swap. The normal variable font supports weights 100-1000. No external font-provider requests are needed.

Source: https://github.com/google/fonts/tree/main/ofl/dmsans
Font: https://raw.githubusercontent.com/google/fonts/main/ofl/dmsans/DMSans%5Bopsz%2Cwght%5D.ttf
